每个阶段使用范围明确的分支／PR，在相关单元、生成文件、构建和 APK 交互检查通过后合并。不得把测试计划、仅编译成功或功能预设状态下的测试记为整体验收。

全新安装测试先于会改写偏好的组件测试执行。测试 APK 与实际应用 APK 安装在新建、无快照恢复的模拟器中，经 Android 界面启用与选择输入法，不预选 MIANCAK 布局，不执行 `ime set`，验证设置先开和输入法先用两条路径。保留关键步骤截图与真实编辑器文本断言。升级测试与全新安装分别记录。

当前环境的实际 APK 构建与 Android 模拟器运行使用 GitHub 托管 runner。物理 ARM 设备没有接入；ARM 包检查与模拟器运行结果分别报告，不宣称完成真机测试。

词表导入／切换（#22）以及 cdict 共同格式迁移（#18）保持独立，不夹带到上述前端里程碑。设计细节见 [LAYOUT_DESIGN.md](LAYOUT_DESIGN.md) 和 [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md)。

本轮版本为 0.2.0（版本码 2）。验收 PR 的检查、合并状态和描述是对应交付记录，源码表中的“已实现”不替代 APK 检查结果。最终 #29 必须通过全部 13 项检查；测试范围与证据入口见 [TESTING.md](TESTING.md)。
