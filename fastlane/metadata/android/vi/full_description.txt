MIANCAK is an experimental, offline Chinese Pinyin keyboard for Android 13 and newer, built on Unexpected Keyboard with the Rime engine.

Type Chinese with touch candidates or switch explicitly to direct English on the same QWERTY geometry. Swipe keys for exact punctuation and symbols. Scroll compact candidates horizontally, or expand within the keyboard area and scroll vertically; more candidates load as needed.

Choose categorized symbols with circular paging across categories. Edit key centers and eight directions in a normal-size preview, including separate Shift actions and paired Fn layouts. Layout files use the Android file picker for import and export. Compatible explicit-Pinyin Rime word tables can be imported and deployed offline; this does not install arbitrary Rime schemes or executable plugins.

The bundled engine uses Wanxiang Base with its offline Simplified Chinese grammar model. The model alone is about 388 MiB, with additional dictionary and compiled-data storage. Compatible custom dictionary YAML remains supported. Normal typing needs no network; wait for candidates during first offline deployment. The app is free and open source under GPL-3.0. Based on Unexpected Keyboard by Julow and contributors; dependency and dictionary credits are preserved in the project.
