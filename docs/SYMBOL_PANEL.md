# 分类符号面板

本文件描述 v0.3.2 已交付的符号浏览与 R5 编辑行为；实际 APK 来源、保留的失败及验证限制见 [输入界面记录](INPUT_UI_FOLLOWUP.md) 和 [执行记录](FN_REPAIR_PROGRESS.md)。当前源码的新变更仍须单独验收。

符号面板使用固定布局 ID `symbols`，固定为字面文字输入。栏目和页码只控制面板内容，不决定语言，不是 Fn 变体。通过布局选择器进入；中文／英文自身的 Fn 功能布局仍完整保留。

| 栏目 | 条目数 | 页数 | 每页首个中心符号 |
| --- | ---: | ---: | --- |
| 常用 | 28 | 1 | ， |
| 标点 | 75 | 3 | ，、‰、⁉ |
| 括号 | 62 | 3 | （、⟨、⦓ |
| 数学 | 117 | 5 | ＋、∯、⊕、⋃、ℕ |
| 箭头 | 89 | 4 | ←、↣、⇇、⤷ |
| 货币／单位 | 68 | 3 | ￥、₹、㎑ |
| 图形／音乐 | 83 | 3 | ○、▪、✕ |

每页最多 28 个中心符号，三行保持旧符号首页的几何坐标。部分数学和箭头键另有相关四斜向符号，例如 `＋` 四角为 `± ∓ ⊕ ⊞`，`∫` 四角为 `∮ ∬ ∭ ∰`。这些是精确文字动作，不是功能键标签。

顶部栏目可横向滚动。点击任意栏目，包括重复点击当前栏目，都回到该栏第一页。右侧显示当前页／总页数。空格左上／右上分别向前／向后翻页；越过栏目边界时进入相邻栏目，全部 22 页首尾循环。源码规则见 `SymbolState.turn`，不是在单栏边界停留。空格上下仍按启用布局顺序轮换，左右保留水平光标滑动。Fn 可见，无特殊效果且不亮起。Enter 右下、退格与 Del 沿用共享控制。

Shift 只使用明确 Unicode 全半角对：U+0021–U+007E 与 U+FF01–U+FF5E 双向配对。`（` 与 `(`、`［` 与 `[` 是配对；`【`、`∫`、`−`（数学减号 U+2212）等没有这类配对，保持原样，不机械映射成别的语义符号。共享控制和功能键不做宽度转换。中文组合切入符号面板时先按原有顺序确认旧组合，再输出字面符号。

栏目和页码保存为独立浏览偏好；损坏值回退常用栏并夹紧页码。设置／主题重建后按实际栏目内容重建键盘，不只恢复页面名称。旋转产生新的编辑会话时，重新进入符号面板保留栏目／页码。

旧 `symbols` 页面及其用户覆盖仍对应“常用”首页，逐行逐列保留。其他页使用 `symbols/<栏目 ID>/<从零页码>` 作为**编辑内容坐标**，不加入输入布局注册表，不能成为 Fn 配对目标。当前 v4 布局文件支持这些独立覆盖，仍接收 v1／v2／v3 文件并保存原始导入文本；无效栏目、页码或动作在写入前整体拒绝。设置中的正常尺寸预览可选择栏目与页，编辑中心、八向、普通／Shift 动作；配对 Fn 的编辑仍属于各自主布局。操作与 H1 高级手势边界见 [可视化编辑器指南](VISUAL_LAYOUT_EDITOR.md)。

自动 APK 场景须逐栏逐页真实触控上述独立首符号样本，验证正文、边界、重复栏目、全半角、无配对保持、相关斜向、Fn 无效果、主题重建及旋转／重新进入。API 35 同时使用系统 1.3 倍字体。没有物理 ARM 设备结果时不作真机保证。
