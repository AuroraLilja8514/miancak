# 布局、页面与切换设计

更新：2026-10-24。本文记录正在梳理的产品设计，尚未实现，不是当前 APK 的操作说明。开发顺序见 [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md)，当前测试范围见 [TESTING.md](TESTING.md)。

## 1. 产品范围

只维护一套面向中文用户的 QWERTY 主键盘骨架。中文、英文配置共用字母位置与常用符号位置，分别进行 Rime 中文组词和英文直接输入。

后续实现时，完全删除继承的其他内置主布局，而不是仅将它们隐藏到高级设置。这取代上一版“保留全部内置主布局并移入高级设置”的提议。保留上游历史、许可证及必要归属信息。未来用户编辑、复制自己的 QWERTY 配置或功能页，与保留原软件全部内置主布局是两件事。

面向用户统一使用“布局／输入页”入口。布局可以采用不同的内容形式，设置中可以启用、排序、修改名称和切换入口：

| 布局／页面 | 内容形式 | 输入用途 |
| --- | --- | --- |
| 中文 QWERTY | 共享主键盘 | 普通字母进入 Rime；显式标点按原样输入 |
| 英文 QWERTY | 同一主键盘的英文配置 | 直接输入英文，不移动普通键位 |
| 数字、符号、希腊／数学 | 静态键盘页 | 输出明确显示的数字、符号、文字 |
| 表情 | 动态内容面板 | 选择并输入表情 |
| 剪贴板 | 动态内容面板 | 选择并插入现有剪贴板内容 |
| 拼音、注音，未来 | 发音符号页 | 直接输入拼音文字或注音符号，详见第 6 节 |

Fn 是可配置的页面切换入口，不要求单独存在一个名字固定为“Fn”的内容页。一个辅助页面被指定为当前主配置的 Fn 目标后，就承担 Fn 页的作用。

内部仍分别记录当前页面、有效中文／英文模式、返回的文字配置和 Shift 状态。统一布局入口不要求把这些状态合并，也不要求将动态面板全部改写为静态 XML。

## 2. 删除主布局与升级迁移

删除其他内置主布局时，同一变更必须处理以下内容：

- 布局源文件、生成的列表和资源、生成器的输入，以及构建与测试引用。
- Android IME subtype 中的默认布局关联、硬编码回退路径和系统语言自动选择行为。
- 原有布局轮换入口，使其进入新页面体系，不再指向已删除的布局目录。
- 已保存的内置布局 ID、系统布局选择及横竖屏选择；不能留下失效引用，或静默回退到另一套非 MIANCAK 主布局。

分清两个阶段：U0 的首次初始化修复应保留当时仍受支持的已有选择；之后 U3 明确退役内置主布局时，才执行有版本的迁移。受影响的旧内置／系统布局配置迁移到 MIANCAK QWERTY，并显示迁移说明、保留原选择记录。有效且不依赖已删除资源的用户自定义配置应保留；无法转换的配置需保留原定义并告知恢复方式。学习数据与无关偏好不随布局清理而删除。

验收需要同时覆盖全新安装、U0 修复升级及 U3 布局退役升级。不能既承诺彻底删除旧布局，又承诺升级后继续运行已删除的内置布局。

## 3. 直接切换与主选择页面

所有入口应调用同一套页面切换逻辑：

| 入口 | 默认设计 |
| --- | --- |
| 中英切换 | 中文 QWERTY 与英文 QWERTY 互换；从辅助页操作时，切到对应目标文字配置 |
| Fn | 当前文字配置与其指定的辅助页互换；中文、英文可配置不同目标 |
| 希腊／数字等专用键 | 进入指定页面；在该目标页再次操作同一切换入口时返回关联的文字配置 |
| Enter 右下滑动 | 打开布局选择面板，不执行 Enter 或编辑器动作 |
| 动态面板的“布局”按钮 | 与 Enter 右下滑动打开同一个选择面板 |

Enter 右下在当前默认控制行中没有显式分配动作。实现时仍需检查动态额外按键与自定义配置的冲突。常规 Enter 和已有编辑器动作入口应保持可用。

选择面板在键盘上部列出当前全部已配置、已启用且可用的布局／页面，支持点击进入并标明当前项。设置页管理启用项、排序及快捷切换目标；尚未实现的未来页面不能作为可用项展示。

打开选择面板时保持预编辑和输入状态；返回键或关闭按钮回到原页面。推荐使用键盘内部区域展示列表／网格，使 IME 高度稳定。它是临时选择界面，不把候选栏永久变成工具栏。任何页面都必须能返回文字输入并重新打开选择器。

只换数字、希腊／数学、表情或其他辅助页面，不自行确认或清空中文组词。之后输入显式文字／符号时，仍按既有规则先确认中文候选，再追加该文字。选择英文配置则遵循已有中英切换规则：确认成功后才变更语言和页面；失败时不能先亮起目标状态。仅打开／关闭选择器不提交文本。

无论从快捷键还是选择器进入同一页面，都应得到相同的输入行为与状态显示。密码、数字等编辑器策略仍需生效，布局选择不得绕过原有输入限制。

## 4. 特殊键亮起的规则

亮起状态由当前有效状态计算，不根据“上次按了哪个按钮”计算：

| 按键／标记 | 状态来源 |
| --- | --- |
| 中／英 | 当前实际语言模式；辅助页也能明确显示所处模式 |
| Fn | 当前页面是否为该文字配置的 Fn 目标页；从选择器进入也应亮起 |
| 希腊、数字等目标键 | 当前是否处于对应目标页，与进入方式无关 |
| Shift | 独立的关闭、一次生效、锁定状态；不能用来表示处于 Fn 页 |
| 布局选择入口 | 选择面板是否打开，以及面板内的当前项 |

当前代码里的 Fn 是修改其他键输出的修饰键，尚不是这种页面切换动作。实现时需使用明确的页面动作；高级自定义若继续支持旧 Fn 修饰语义，应使用可区分的名称／状态，不能共用一个模糊的锁定标志。

中英文共享骨架切换保持 Shift 的独立状态。进入不同功能页面时，建议清除一次性修饰状态与旧 Fn 临时状态；显式大写锁定独立保存，仅在支持它的页面显示和生效，返回文字页时仍可辨认。完整切换表必须在实现前确认，并测试锁定状态下进入／离开各页。

## 5. 可视化布局设置，未来

先选择布局／页面，再进入编辑。静态页支持点击某个键，选择中心或角位，设置显示文字、准确的字面输出或明确的语义动作，并预览普通／Shift 两层结果。

各页面共用稳定的标识和切换配置。中文／英文主配置引用同一份几何，避免只编辑一边导致普通键位置不同。允许复制用户配置、修改快捷切换目标、启用与排序，并提供冲突提示、保存／取消、单键／整页恢复、导入导出及配置版本迁移。

表情与剪贴板也可选中设置。它们的编辑对象是面板布局、分类／显示选项、控制键与切换入口；实际表情和剪贴板记录由各自数据来源提供，不将每条动态内容固化为布局文件。

保存布局后必须验证实际触控行为，而不只看预览：标签与输出一致、引擎动作与字面动作可区分、切页和亮起状态正确、重启／升级后设置保留、错误导入不破坏有效配置，且始终有可用的返回与恢复入口。

## 6. 中文 Fn 的拼音／注音页，未来

这里将“输入拼音”解释为直接输出 `nǐ hǎo` 一类带调拼音文字；将注音解释为直接输出 `ㄋㄧˇ` 一类符号。它们是显式文字输入页，不等于为 Rime 新增注音选汉字方案。若还需要后者，应另外定义引擎输入与方案范围。

这些页面实现后，可在设置中选择中文 Fn 的目标是“拼音”还是“注音”；被启用的另一个页面仍可从布局选择器进入。Fn 再次操作返回关联的中文文字页。英文配置的 Fn 目标独立设置。

拼音页的工作草案为：韵母键中心输出不带调的形式，四角分别输出第一至第四声，所有韵母的方向约定相同。例如暂按左上、右上、左下、右下对应一、二、三、四声：

| 中心 | 左上：一声 | 右上：二声 | 左下：三声 | 右下：四声 |
| --- | --- | --- | --- | --- |
| a | ā | á | ǎ | à |
| ang | āng | áng | ǎng | àng |
| iu | iū | iú | iǔ | iù |
| ui | uī | uí | uǐ | uì |
| ü | ǖ | ǘ | ǚ | ǜ |

这是一张动作示例表，不是完整键盘。需要先列全声母、韵母、标点和控制键，再核算键数；必要时采用声母／韵母分组或子页。不能承诺所有组合都塞进原来的 26 个主键。中心无调形式可用于轻声拼写；不另外添加一个“第五声变音符号”。

四个角位已经用于声调，标点应保留专用键／控制区域或可直接到达的标点页。原先“最下面字母行左上放中文标点”的约定针对 QWERTY 主布局；拼音页需单独排布，避免角位冲突。保持空格、删除、常用中英文标点、返回与布局选择入口可达。

内置输出按拼音标调规则逐项审查，特别覆盖复韵母、`iu`／`ui`、`ü`、大小写和 Unicode 显示／删除。直接输出键按键面提交字符／字符串，不暗中改写前一个声母或已输入音节；整音节拼写辅助是另外的功能。不能将普通拼音页的带调字母发送到当前全拼方案，假定它会生成汉字候选。

注音采用独立的符号及调号设计，不把拉丁字母上的变音符号机械套过去。需核对阴平、其他声调、轻声及横排位置，并明确对应按键动作。声调规则参考[汉语拼音方案](https://www.moe.gov.cn/jyb_sjzl/ziliao/A19/195802/t19580201_186000.html)、[汉语拼音正词法基本规则](https://www.moe.gov.cn/ewebeditor/uploadfile/2015/01/13/20150113091717604.pdf)和[国语注音符号手册](https://language.moe.gov.tw/001/Upload/files/site_content/M0001/juyin/html_ch/index.html)。这里只引用规则，不引入手册图片、字体或音频资源。

## 7. 实现顺序与验收

1. 完成 U0–U2 的首次安装、基础标点／Shift 和候选栏。
2. U3 建立统一页面与状态规则、主选择面板，完成其他内置主布局的删除与迁移。先形成可检查的默认键位表和切换表，不重写 Rime 核心或手势引擎。
3. U4 的设置、介绍、帮助及无障碍更新跟随各功能交付。
4. U5 可视化编辑、U6 拼音／注音页各自作为后续功能实现，不与 Rime 词表管理或 cdict 数据格式迁移绑定。

每条切换路线均需检查最终页面、有效模式、修饰状态、亮起状态和编辑器文本。包括选择器取消、快捷键往返、从选择器进入 Fn 目标、组词中切页、旋转／重建、禁用当前页、删除快捷目标后的配置校验、升级迁移和恢复默认。页面 ID／快捷目标无效时应给出明确恢复路径，不能留下无法返回的键盘。

## C3 实现记录（待 APK 验收）

页面注册表现由 `PageConfig` 与 `PageState` 统一驱动：中英共享 QWERTY，符号、数字、希腊／数学、表情与剪贴板可启用、排序及指定 Fn 目标。Enter 右下滑动打开键盘区域内的选择器，表情及剪贴板另有可见入口。打开选择器及辅助页不确认拼音；选择中英配置则在确认成功后进入。Fn 亮起取决于当前页面与当前语言的目标是否相同。

其他内置主布局文件及 Android 子类型已删除。一次性迁移将旧内置布局选中项映射到 MIANCAK，保留原 `layouts` 内容于 `miancak_previous_layouts`，并保留可解析的自定义 XML 及其选中位置。此项是明确的布局退役迁移，与首装默认值修复分开验收。

## C4 可视化键位编辑（待 APK 验收）

“布局与页面”可按页面打开可视化键位编辑器；点选按键后通过 3×3 位置格修改中心、四角及四向，Shift 层独立预览和编辑。支持原样文字、引擎文字、常见键盘功能、留空和使用默认。保存前是草稿，取消不改设置，旋转保留草稿。每个位置拥有独立 Shift 输出，避免同名字符之间串用映射。

顶部候选状态栏保留不可编辑的布局选择入口，便于从自定义页面返回。表情／剪贴板只编辑控制行。页面设置可通过 Android 文件选择器导出或导入版本 1 JSON；导入先完整校验版本、大小、页面、键位与功能，失败不改现有配置。保存和导入保留上一次完整配置，可恢复。编辑坐标先于横屏拆分等显示变换应用；数字页统一同一份逻辑键位。

## C5 拼音／注音文字页（待 APK 验收）

新增拼音文字、36 韵母与注音文字三个可设置页面。拼音 QWERTY 的 `v` 输出 `ü`，元音或韵母四角为一至四声，中心不标调；Shift 可输出对应大写。注音四角输出相应符号及声调，一声不额外标记；轻声点在独立标点键。底部标点不会占用声调位置，韵母页空格左上为退格。所有页面通过选择器可达，也可设为中文／英文 Fn 目标。

这些页面输出原样文字，可输入 `nǐ hǎo`、`ㄋㄧˇ`；不暗示已经提供注音转汉字方案。默认 Fn 保持原有符号页，用户可在设置中改为拼音或注音。已保存的页面启用列表不被扩充覆盖，新页可在设置启用。
