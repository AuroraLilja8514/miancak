# 可视化布局编辑（R5）

状态：R5 已通过 API 23／35 的真实 APK 端到端验收；正式词包组合的 R7 总验收另行记录，结果见 [执行记录](FN_REPAIR_PROGRESS.md)。

设置 → 布局与页面 → 选择布局的编辑按钮。预览复用实际键盘的尺寸和绘制方式，不再将每个键扩大为三乘三网格。点击直接编辑中心，向四正向／四斜向滑动直接编辑对应位置，包括当前为空的位置。预览上的滑动只用于选择设置，不会输入、重复或切换布局。页面可上下滚动，保存／取消固定在顶部。

需要大按钮或辅助功能时，使用“按键与方向列表”，选择具体按键后再选中心、八向或逆时针。

“Shift 层预览”查看或编辑该层。未单独覆盖时沿用继承规则；单独指定 Shift 不会嵌套或更改普通层。预览注明继承、覆盖、清空、跟随普通层及共享只读状态；“·”表示该位置无输出。中心即普通点击，不是额外的方向键。

可选动作包括字面文字、引擎编码及具名功能。真实 F1–F12 发送 Android 按下／抬起事件；方向 Slider 是可连续移动的动作，不能用同名文本代替。输入自定义文字可包含多个字符，字面文字不会被当成拼音交给引擎。

“编辑配对布局”在同一未保存草稿内对照基础／Fn 两个定义，分别保存各自覆盖，不修改配对跳转。Fn 始终只在明确的当前配对间切换。符号布局可选择具体栏目及页；这些内容页不是输入布局，也不抢占 Fn。

点击清空只清空当前层；恢复继承只去掉当前层覆盖；恢复此位置会同时去掉该位置普通／Shift 两层覆盖；重置布局只影响当前编辑范围。取消放弃整个草稿。旋转保留草稿、当前范围、Shift 预览与滚动位置；若持久配置被另一处修改，保存会提示冲突，避免覆盖新配置。

空格中心／四正向、方向键控制区、Enter 与右下选择器、退格与右上 Del 等已约定共享位置显示只读，不能在某个布局里单独改成另一个意思。没有新增共享控制改键功能。emoji／剪贴板只编辑固定控制行，其动态正文由对应面板管理。

文件导入／导出使用同一位置与动作格式，v4 接受旧 v1／v2／v3；旧常用符号页覆盖坐标保留。恢复上次配置和词表／学习数据分开处理。预览中的顺时针选择中心的 Shift 输出，折返选择对应方向的 Shift 输出；修改前会说明这也影响 Shift 点击／滑动。逆时针选择原有独立 anticircle 输出，普通／Shift 层分别保存，文件位置编号为 9。没有增加独立的顺时针规则或 H1 高级手势规则编辑，运行时保留原有 Shift 优先、Fn 回退的求值。Compose 保持原状。
