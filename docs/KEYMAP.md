# 中文 QWERTY 键位

普通字母位置与中英文模式无关。“Shift 后”表示先点 Shift，再向该角滑动，全部可以单指完成。双击／长按 Shift 锁定，再点解除。Shift 右上滑动切换中英文，不再放独立 Caps Lock。

## 最下面字母行的左上角

| 按键 | 左上 | Shift 后左上 |
| --- | --- | --- |
| Shift | （ | ( |
| Z | 、 | / |
| X | ！ | ! |
| C | 。 | 。 |
| V | ， | ， |
| B | ？ | ? |
| N | ； | ： |
| M | ’，分音／右单引号 | ' |
| 退格 | ） | ) |

句号与逗号的英文形式仍在 C／V 左下角，能够与中文形式连续使用。N 右上为英文冒号，左下为英文分号。括号旧位置保留；额外成对中文符号在“标点与符号”页。

## 引号和分音

| 位置 | 普通状态 | Shift 后 |
| --- | --- | --- |
| M 左上 | 中文组词时分音，否则输入 ’ | ' |
| M 左下 | ' | ‘ |
| M 右上 | " | “ |
| M 右下 | ” | " |

M 左上的 `’` 是明确的分音动作：正在中文组词时向引擎发送 ASCII 分隔符，不确认当前候选、不把引号输入正文；其他情况下按键面输入 `’`。例如 `xi`、分音、`an` 可得到“西安”。要在组词后追加正文引号，可以先选词再输入引号，或在自定义布局使用明确的字面引号动作。Shift 后的 ASCII 单引号是字面输入，会先确认组词再追加 `'`。

Rime 词表编码仍使用原有格式，不将词表中的分隔符批量替换为中文引号。自定义布局可以继续区分 `pinyin_separator`、显式 `:engine:` 与 `:literal:`。

## 页面和设置

Enter 右下滑动或顶部 `▦` 打开布局选择器。Fn 为可设置页面切换键，默认中文目标为符号、英文目标为数字；再次按下返回当前语言主页面。Fn 的亮起状态取决于当前页面，而非最后按下的键。

Ctrl 左上进入希腊／数学、左下进入剪贴板、右下进入数字；Fn 左下为表情，右下为设置。主页面空格上下仍可按配置顺序轮换页面。表情和剪贴板保留可见选择器入口。

“布局与页面”可启用／排序页面、选择 Fn 目标、可视化编辑键位及独立 Shift 层。导入导出采用版本化布局文件；这些设置不会导入 Rime 词表。拼音／注音文字页的声调四角和底部独立标点见 [LAYOUT_DESIGN.md](LAYOUT_DESIGN.md)。通过情况见 [TESTING.md](TESTING.md)。
