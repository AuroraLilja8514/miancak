# N1/N2 默认偏好与兼容性

2026-11-16：以已发布 v0.3.2 后的 `master`（`4ee785138c5a01029c2d6687523bcdef6207200d`）为基线实现，目标开发版本 0.3.3／versionCode 6。该版本尚未发布，下面的测试场景已加入源码，不等于实际 APK 验收已经通过。

## 默认值

| 字段 | 缺失时的新默认 | 保留的可选行为 |
| --- | --- | --- |
| `split_layout` | `never` | 用户仍可选择 `wide` 或 `landscape`；运行时缺省与设置 XML 一致 |
| `extra_key_superscript` | `true` | 可在额外按键设置中关闭 |
| `extra_key_subscript` | `true` | 可在额外按键设置中关闭 |

这些是缺省策略，不是新的迁移版本。初始化不写入这些字段，不改变原有配置的来源判断，也不修改字面／引擎路由、Shift、Fn、Sup/Sub 转换或槽位求值规则。

## 旧配置与恢复

- **所有已保存的值均保留。** 旧设置页会在打开时自动保存 `split_layout=wide` 和 Sup/Sub 的 `false`。这些值无法可靠地区分为自动初始化还是主动选择，因此均保持原样，不能声称它们证明用户曾主动设置。
- 缺失字段立即采用新默认；通过设置再次手动选择时，以保存值为准。移除单独字段后重新采用新默认，不清除其它偏好。
- 现有布局／页面重置只管理对应布局／页面，不是全局偏好恢复入口。它们不负责重置分体或额外按键开关。
- Sup/Sub 使用现有空位注入规则，不能覆盖已占用的自定义 XML 动作。逐位置普通／Shift 覆盖在额外键准备后应用，继续优先于默认按键；密集自定义布局可因无空位而不显示某个额外键。
- 符号内容、emoji 和剪贴板动态面板不注入文字布局额外键；数字／希腊等原先已有的 Sup/Sub 不被重新定义。
- 本次不改 applicationId、偏好存储位置、布局 JSON 格式、词表部署或学习目录。

## 验证分工

- `SplitLayoutDefaultsTest` 检查实际设置 XML、运行时／独立预览和重复初始化；交叉 360、599、600、840dp、横竖屏、折叠／展开配置，保留 `wide`、`landscape`、`never` 及未知已存值，并检查单独移除字段不影响其它设置。这是配置模拟，不是折叠真机验收。
- `ExtraKeyDefaultsTest` 检查两个字段分别缺失／开启／关闭的九种组合、实际设置复选框、中文／英文／Fn 的正常和 Shift 语义、F1–F12、自定义 XML／逐层覆盖，以及全部符号页和动态面板的排除。
- 当前两个 API 35 `first-install` 场景分别从设置或 IME 开始，再通过正常 Android 界面启用和选择输入法，不预写本应用偏好。检查实际 Sup/Sub＋数字上屏、两个横屏方向、恢复竖屏、设置中的手动分体／关闭，以及进程重开和真正重启后的回访。早期矩阵保留为历史。
- Fn 接收端场景在四个主布局分别点击 Sup/Sub 后输入 `n`，检查实际正文 `ⁿ`／`ₙ`，不以键帽或预览代替上屏。
- 旧 APK 升级夹具打开旧版真实设置，使其自动保存旧默认，再检查替换与真实重启后仍保留；既有布局、词表及非空学习检查不删除。

CI 仍需运行相关生成、单元、三 ABI debug／release 和真实 APK 检查。原失败、未运行阶段和新成功分别记录；不以模拟配置、编译成功或历史通过代替当前实际 APK 结果。正式签名与发布流程不在此改动中执行。
