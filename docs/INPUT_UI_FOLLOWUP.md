# 输入界面后续修复（2026-10-26）

基线：PR #32 的 b892180；本轮版本 0.3.2（code 5）。状态：实现已提交，真实 APK 验收进行中；未完成的测试不计通过。

## 修复范围

- 候选：移除前后页按钮，保留展开键；紧凑栏可横向滚动，左右内边距从 14dp 减为 6dp，移除 64dp 最小宽度。展开时紧凑栏回到左端，保留能完整容纳的排名前缀；后续候选在键盘区域按宽度排列，行内分配剩余空间，可上下滚动。候选按需从 Rime 迭代器扩充，不再限于当前 10 项菜单。选择索引与所显示窗口绑定，旧 revision／editor 的点击和加载请求不能作用于新输入。
- 符号：门类内前后翻页跨类别循环，首尾相接；点击栏目仍回该类第一页。栏目视图和滚动位置复用，只将新选中且被裁切的栏目直接移入视口，移除从第一个栏目开始的滚动动画。文本布局额外按键、数字行及侧边小键盘不插入固定符号内容，用户显式符号编辑仍保留。
- 括号：中文基础及配对 Fn 的 K 左上／右上提供 （／），Shift 为英文小括号；英文 K 和原有其它输出保留。
- 编辑器：真实尺寸键盘，点击、八向、顺逆时针及折返用于选择设置；顺时针／折返沿用 Shift 对应位置，逆时针对应原有独立输出。保留大按钮列表作为辅助入口；共享控制只读，保存／取消、旋转草稿、Fn 对照及导入导出继续保留。文件 v4，兼容 v1–v3；Compose 不改，H1 独立高级规则仍后置。
- 横屏：设置的百分比预算先扣除约 64dp 候选／状态或符号栏，再分配键区；保留已有百分比，最小行高 24dp。缩小横屏候选／符号栏，保留原有横屏字符缩放以保证压低后的键帽可读，默认横向留边与竖屏一致；左右采用相同安全边距，遵循父视图实际分配宽度。

首轮两个系统均完成 7 项词表 native 测试和 39 项设备组件测试，Fn 与全部符号页实际输入、跨类循环和栏目视图保留通过；交互停在预览顺时针选择：同角度区间的重复采样被传入只应接收方向变化的识别器。预览现跳过未变的角度区间，并用包含重复点的插值轨迹回归；运行时原有手势规则不因此变更。

第二轮 CI 40323146017 的编译发现项目没有启用 BuildConfig 生成，已在构建中明确启用，随后仍须完整重跑。增加关闭分体与侧边数字键盘后两个横屏方向的实际输入截图与视口检查，直接覆盖本次反馈场景。

横屏行高压低后，滑动触发距离也按行高缩放，避免沿用较高键盘的阈值导致空格上／下等四正向难以触发。验收增加横屏短上滑到数字布局、短下滑返回符号布局的实际操作，保证共享控制含义和可达性。

默认横屏阈值约为行高的 45%，同时保留用户灵敏度比例；底排 Space 的向下移动也必须在触及屏幕边缘前能触发，不能只用未受边缘裁切的上滑估算。

编辑器绘制还明确使用当前选定的键盘主题与背景，而非设置 Activity 的主题。实际页面检查键帽文字非透明且与按键颜色不同，保留正常预览截图供视觉复核，避免只按坐标成功而漏掉不可见键帽。

CI 40327240265 的 API 23 旧 APK 准备失败现场：已安装的旧版服务列在系统 Input Methods 中，但 enabled 列表与选择器均未包含它，升级尚未开始。夹具现只在 prepare 阶段核对旧版启用前置条件，并在包注册完成后请求启用、限 15 秒等待确认；verify/reboot 不补写启用状态，保留 APK 替换与重启前后的原始保留检查。同轮另一个 API 23 任务在 SDK 下载时收到损坏 ZIP，未安装应用，按环境失败保留。

同轮两组交互继续暴露预览逆时针误选中心：预览只读取识别器最终状态，而实际 Pointers 在识别器后续反转／取消时仍保留上一次有效圆周输出。预览改为沿用这个既有有效选择；新增取消后有效输出回归，并在实际预览操作后先核对动作对话框中的方向与 Shift，再写入草稿，避免测试误改中心后才发现。运行时 Pointers／Gesture 求值保持原样。

CI 40331284727 的独立空 API 23 重启门禁在首次与一次新客体重试中均超时，APK 测试因此被全局跳过。这些测试本来分别运行在不同主机／客体，调度现去掉这个错误的跨主机前置依赖：独立三重启检查仍保留原有断言并影响 CI 总结果，但不再阻止其它客体执行 APK 验收；升级、词表任务自己的真实重启与保留断言不变。门禁失败报告新增最后观测的 boot ID／boot_completed，以及失败后重新读取的状态，避免把早先的 offline 消息当作完整根因。
