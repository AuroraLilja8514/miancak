# 分类符号面板

本文件描述 R4 当前源码；APK 验收结果见 [执行记录](FN_REPAIR_PROGRESS.md)，未执行或失败的场景不算通过。

符号面板使用固定布局 ID `symbols`，固定为字面文字输入。栏目和页码只控制面板内容，不决定语言，不是 Fn 变体。通过布局选择器进入；中文／英文自身的 Fn 功能布局仍完整保留。

| 栏目 | 条目数 | 页数 | 每页首个中心符号 |
| --- | ---: | ---: | --- |
| 常用 | 28 | 1 | ， |
| 标点 | 75 | 3 | ，、‰、⁉ |
| 括号 | 62 | 3 | （、⟨、⦓ |
| 数学 | 117 | 5 | ＋、∯、⊕、⋃、ℕ |
| 箭头 | 89 | 4 | ←、↣、⇇、⤷ |
| 货币／单位 | 68 | 3 | ￥、₹、㎑ |
| 图形／音乐 | 83 | 3 | ○、▪、✕ |

每页最多 28 个中心符号，三行保持旧符号首页的几何坐标。部分数学和箭头键另有相关四斜向符号，例如 `＋` 四角为 `± ∓ ⊕ ⊞`，`∫` 四角为 `∮ ∬ ∭ ∰`。这些是精确文字动作，不是功能键标签。

顶部栏目可横向滚动。点击任意栏目，包括重复点击当前栏目，都回到该栏第一页。右侧显示当前页／总页数。空格左上／右上只在当前栏目内上／下翻页；边界显示灰色并保持原页，不循环到另一栏目。空格上下仍按启用布局顺序轮换，左右保留水平光标滑动。Fn 可见，无特殊效果且不亮起。Enter 右下、退格与 Del 沿用共享控制。

Shift 只使用明确 Unicode 全半角对：U+0021–U+007E 与 U+FF01–U+FF5E 双向配对。`（` 与 `(`、`［` 与 `[` 是配对；`【`、`∫`、`−`（数学减号 U+2212）等没有这类配对，保持原样，不机械映射成别的语义符号。共享控制和功能键不做宽度转换。中文组合切入符号面板时先按原有顺序确认旧组合，再输出字面符号。

栏目和页码保存为独立浏览偏好；损坏值回退常用栏并夹紧页码。设置／主题重建后按实际栏目内容重建键盘，不只恢复页面名称。旋转产生新的编辑会话时，重新进入符号面板保留栏目／页码。

旧 `symbols` 页面及其用户覆盖仍对应“常用”首页，逐行逐列保留。其他页使用 `symbols/<栏目 ID>/<从零页码>` 作为**编辑内容坐标**，不加入输入布局注册表，不能成为 Fn 配对目标。v3 布局文件支持这些独立覆盖，仍接收 v1/v2 文件并保存原始导入文本；无效栏目、页码或动作在写入前整体拒绝。完整的栏目页编辑入口和中心加八向预览将在 R5 接入，不将本节当成编辑器已完成。

自动 APK 场景须逐栏逐页真实触控上述独立首符号样本，验证正文、边界、重复栏目、全半角、无配对保持、相关斜向、Fn 无效果、主题重建及旋转／重新进入。API 35 同时使用系统 1.3 倍字体。没有物理 ARM 设备结果时不作真机保证。
