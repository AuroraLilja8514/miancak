# MIANCAK 0.3.3（开发中，未发布）

这是 0.3.2 正式发布后的 N1/N2 默认偏好改进，当前仅供开发与验收。

- 新安装或缺失 `split_layout` 字段时，宽屏、横屏及折叠状态均默认不分体。设置仍可主动选择宽屏／横屏分体。
- 新安装或缺失相应字段时，中文、英文及配对 Fn 主键盘默认启用现有 Sup/Sub 修饰键。它们继续使用原有单指修饰语义，不改变字符转换规则。
- 保留所有已保存的分体与 Sup/Sub 值，包括旧设置页自动写入且无法区分是否主动选择的值；不通过版本升级强制重置键位、词表或个人学习。若需要新默认，可在设置中关闭分体、开启 Sup/Sub。
- 密集自定义布局不为显示额外键而覆盖已有动作；符号、emoji 与剪贴板内容不因此新增额外键。

相关配置、迁移和测试边界见 [默认偏好说明](../DEFAULT_PREFERENCES.md)。N3 设置对齐、N4 项目身份与入口、H1 高级手势编辑仍不在本次范围。

本文件不是发布公告。没有创建版本标签或新 Release；正式下载仍为 v0.3.2。后续版本只有在确切源码的适用检查、审查与正式 APK 验收完成后，才能按 [发布约定](../RELEASING.md) 交付。ARM 真机、独立密钥备份恢复及新的两版本正式签名升级未由本次源码修改证明通过。
