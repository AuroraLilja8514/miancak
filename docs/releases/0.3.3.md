# MIANCAK 0.3.3（开发中，未发布）

这是 0.3.2 正式发布后的 N1/N2 默认偏好、N4 项目入口与 Android 支持范围改进，当前仅供开发与验收。

- 新安装或缺失 `split_layout` 字段时，宽屏、横屏及折叠状态均默认不分体。设置仍可主动选择宽屏／横屏分体。
- 新安装或缺失相应字段时，中文、英文及配对 Fn 主键盘默认启用现有 Sup/Sub 修饰键。它们继续使用原有单指修饰语义，不改变字符转换规则。
- 保留所有已保存的分体与 Sup/Sub 值，包括旧设置页自动写入且无法区分是否主动选择的值；不通过版本升级强制重置键位、词表或个人学习。若需要新默认，可在设置中关闭分体、开启 Sup/Sub。
- 密集自定义布局不为显示额外键而覆盖已有动作；符号、emoji 与剪贴板内容不因此新增额外键。

- 最低安装版本提高到 Android 13（API 33）；编译／目标 SDK 仍为 36，运行验收聚焦 Android 15（API 35）。保留旧 APK 覆盖安装、全部三种 ABI、签名和重启门禁；支持范围变化不重置数据。
- 项目／源码与反馈分别指向 MIANCAK 仓库及 Issues；更新当前使用说明和商店文本，保留上游致谢与来源。旧商店图片仍待当前应用截图和视频复核，不视为本版证据。
- 修复剪贴板历史按新到旧排序时，固定较旧条目可能误清空较新系统剪贴内容的问题。保留现有固定当前条目时的清空策略、历史时限和私有存储格式；见[剪贴板修复与验收边界](../CLIPBOARD_HISTORY.md)。
- 布局编辑／文件导入会拒绝完整动作定义之外的多余文字，避免将 `:literal:'你好'junk` 静默解释为前半段。导入失败保留原配置；现有已保存动作继续兼容读取，不自动重写。
- 布局文件导入会拒绝无效或截断的 UTF-8，并提示重新保存文件；不再用 `�` 静默改变按键文字。有效 Unicode 文字保持原样，原有文件大小与完整配置校验继续适用。
- 修复词表表头的注释／引号解析：版本文字中的 `#` 和普通撇号保持原样，注释需要空白分隔；错误的单引号拼接会拒绝导入。原有词表目录与学习数据不自动重写，数据格式及导入上限保持不变。

相关配置、迁移和测试边界见 [默认偏好说明](../DEFAULT_PREFERENCES.md)。[Android 支持范围](../ANDROID_SUPPORT.md) 说明新旧 APK 角色及仍待验证项。N3 设置对齐尚未合入此独立切片，H1 高级手势编辑仍不在本次范围。

本文件不是发布公告。没有创建版本标签或新 Release；正式下载仍为 v0.3.2。后续版本只有在确切源码的适用检查、审查与正式 APK 验收完成后，才能按 [发布约定](../RELEASING.md) 交付。ARM 真机、独立密钥备份恢复及新的两版本正式签名升级未由本次源码修改证明通过。
