# 中文 QWERTY 键位

> 适用：0.3.1 的普通 QWERTY 默认键面。Fn 配对、变体具体位置与共享控制见 [FN_LAYOUTS.md](FN_LAYOUTS.md)，分类符号与八向编辑见 [执行记录](FN_REPAIR_PROGRESS.md)。用户覆盖后的实际输出以自己的配置为准。

普通字母位置与中英文模式无关。“Shift 后”表示先点 Shift，再向该角滑动，全部可以单指完成。双击／长按 Shift 锁定，再点解除。Shift 右上滑动切换中英文，不再放独立 Caps Lock。

## 最下面字母行的左上角

| 按键 | 左上 | Shift 后左上 |
| --- | --- | --- |
| Shift | （ | ( |
| Z | 、 | / |
| X | ！ | ! |
| C | 。 | 。 |
| V | ， | ， |
| B | ？ | ? |
| N | ； | ： |
| M | ’，分音／右单引号 | ' |
| 退格 | ） | ) |

句号与逗号的英文形式仍在 C／V 左下角，能够与中文形式连续使用。N 右上为英文冒号，左下为英文分号。括号旧位置保留；额外成对中文符号在“标点与符号”页。

## 引号和分音

| 位置 | 普通状态 | Shift 后 |
| --- | --- | --- |
| M 左上 | 中文组词时分音，否则输入 ’ | ' |
| M 左下 | ' | ‘ |
| M 右上 | " | “ |
| M 右下 | ” | " |

M 左上的 `’` 是明确的分音动作：正在中文组词时向引擎发送 ASCII 分隔符，不确认当前候选、不把引号输入正文；其他情况下按键面输入 `’`。例如 `xi`、分音、`an` 可得到“西安”。要在组词后追加正文引号，可以先选词再输入引号，或在自定义布局使用明确的字面引号动作。Shift 后的 ASCII 单引号是字面输入，会先确认组词再追加 `'`。

Rime 词表编码仍使用原有格式，不将词表中的分隔符批量替换为中文引号。自定义布局可以继续区分 `pinyin_separator`、显式 `:engine:` 与 `:literal:`。

## 页面和设置

Enter 右下滑动或顶部 `▦` 打开布局选择器。Fn 只在当前布局及其明确配对变体之间往返，中英文分别有自己的变体；符号面板 Fn 可见但无特殊效果。Fn 亮起状态来自实际布局 ID。

Ctrl 左上进入希腊／数学、左下进入剪贴板、右下进入数字；Fn 左下为表情，右下为设置。主页面空格上下仍可按配置顺序轮换页面。表情和剪贴板使用底部 Enter 右下进入选择器，顶部重复整行按钮已删除。中文空格左上默认进入拼音文字，可设置为注音；发音文字页 Shift 右上返回中文。

“布局与页面”可启用／排序布局、选择自身 Fn 变体编辑、设置拼音／注音入口、编辑键位及独立 Shift 层。导入导出采用版本化布局文件；这些设置不会导入 Rime 词表。拼音／注音文字页的声调四角和底部独立标点见 [FN_LAYOUTS.md](FN_LAYOUTS.md)。通过情况见 [TESTING.md](TESTING.md)。

## 0.3.2 界面修复

中文基础／Fn 的 K 左上、右上分别提供 `（`、`）`，Shift 输出 `(`、`)`。符号空格左上／右上跨栏目循环翻页，顶部栏目保留并指示当前位置。候选栏移除左右按钮，支持横向滚动，展开后显示从第一项开始的紧凑行和可纵向滚动的后续候选。编辑器入口及手势选择见 [可视化编辑](VISUAL_LAYOUT_EDITOR.md)。
