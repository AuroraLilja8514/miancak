# 正式中文词包评估（R6）

状态：候选准备及标准已固定，尚未取得本轮真实 APK 结果，生产默认仍为旧词典。

## 数据边界

候选采用 [rime-ice 固定提交](https://github.com/iDvel/rime-ice/tree/da1fbe602e38f26db846fa10120ee64c2b0324c0) 的 `cn_dicts/8105.dict.yaml`、`base.dict.yaml`、`ext.dict.yaml` 三个纯词表。仓库声明 GPL-3.0-only；逐文件 SHA-256、原始行数见 `native/word-pack.lock.json`，原始文件保持在锁定源码缓存中。字表头还记载维基词典、北语字频数据；基础及扩展表头保留各自上游来源。不得将仓库级声明当作所有上游资料来源相同。

按 8105 → base → ext 顺序合并；同一正文及编码的完全重复项保留首次出现的权重，保留其他所有读音和原始权重。生成报告记录重复数量、实际行数、输入／输出哈希。移除的仅是供 librime 使用的合并文件中的注释和重复行；原始文件与来源不改。实际 `WordTable` 解析完整原始三表，来源／更新注释不计入有效 YAML 的 64 KiB 预算，文件 64 MiB 与单行 16 KiB 限制仍适用。

不安装第三方 schema、Lua、OpenCC 或整套万象方案。雾凇的 `tencent` 无编码列、`others` 部分无编码及根表大写／无编码混合词条尚不属于当前导入配置；不静默跳过后声称完整支持。这里只评估明确选定的三个完整纯词表。

万象候选版本已读取固定来源 [2685894d88be6dc7f15e79937ac3a6eb918accce](https://github.com/amzxyz/rime-wanxiang/tree/2685894d88be6dc7f15e79937ac3a6eb918accce)，已核对其根词表与字表：`wanxiang.dict.yaml` 引用 zi／jichu／cuoyin／duoyin／diming／mingren／yiren；字表第二条即为 `阿 → ā`（Git blob `038a106edb471982b49c83f209834db0e1984bbb`），当前明确无声调导入配置会报错。基础文件约 49.5 MB，还需逐表处理带调编码、归并后的重复／权重和来源；不能直接去调后声称等价兼容。`custom/wanxiang_pure.dict.yaml` 仍引用 `.pro` 数据，不是当前无声调配置的快捷替代。因此本轮优先评估原样兼容的雾凇三表，万象规范化转换另行跟踪，不引入完整万象方案。

## 预先固定的比较方法

同一 MIANCAK schema 与引擎参数，不改分词规则，不下载在线数据；旧词典及候选分别用空用户目录，禁用个人学习，使用真实 JNI。候选评估资产只进入测试 APK，未接入生产默认。

`androidTest/assets/quality/corpus.tsv` 固定 70 个基础用例：聊天 20、工作 20、日常 10、地名 7、人名 3、多音词 10；另有 6 个长句用于诊断。歧义人名明确列出可接受输出。测试读取接收候选及确认正文，而非比对词条存在或词条总数。

采用门槛在首次运行前固定：基础用例首选至少 80%，前五至少 95%，两项均不能低于旧词典；模拟器测试进程 PSS 不超过 512 MiB、冷部署不超过 180 秒、基础输入 JNI P95 不超过 200 毫秒。长句单独报告准确输出、切分／拼音及确认正文，不掺入基础分数；这组小样本不能代表无限制自然语言输入质量。

每种 API 23/35 生成 `word-pack-quality.json`，逐项列出实际候选、预期可接受项、排名、确认正文及耗时；同时报告部署体积和内存。若不达标，记录缺口并改善数据或参数后重新运行，不能为变绿而修改预期词频。

## 采用后的迁移要求

只有比较结果与部署资源通过后才切换内置默认。保持 `pinyin_simp` 词典及 `miancak_pinyin` schema 标识，沿用稳定用户学习目录；保留自选基础表、附加表和现有原子回滚。旧 0.3.0 数据需有离线回退入口，切换不能删除学习数据库。正式采用时再更新内置来源声明、软件内说明、导入文档与验收结果。
