# 修复分支的 Fn 布局

适用：0.3.1 修复候选。是否通过 APK 验收，以 [执行记录](FN_REPAIR_PROGRESS.md) 的具体提交为准。本说明不表示 R3–R7 已经完成。

## 配对与入口

| 当前布局 | Fn 目标 | 输入策略 |
| --- | --- | --- |
| `zh` ↔ `zh_fn` | 只在中文基础布局与中文 Fn 变体之间切换 | 中文拼音引擎；明确字面符号仍提交原文 |
| `en` ↔ `en_fn` | 只在英文基础布局与英文 Fn 变体之间切换 | 直接输入 |
| `numeric` ↔ `numeric_fn` | 数字布局与其函数／符号变体 | 直接输入 |
| `greek` ↔ `greek_fn` | 希腊／数学布局与其替代字形变体 | 直接输入 |
| 符号、表情、剪贴板、拼音文字、韵母、注音 | 没有 Fn 配对；其中现有 Fn 键不切换布局 | 固定直接输入 |

从 Enter 右下或候选栏选择器直接进入变体，Fn 同样亮起。Shift 右上中英切换保持基础／变体对应关系；发音文字及其他辅助布局的返回目标固定为中文主布局。隐私／数字字段无法启用中文引擎时，返回采用英文主布局。

“布局与页面”中可分别选择基础布局与其 Fn 变体进行编辑。原来的“选择任意 Fn 目标”对话框已替换为编辑自身变体的入口。可选数字／希腊布局与自己的变体一起启用或停用；中文／英文配对保留，避免失去主输入入口。

## 默认键位与上游保留

| 操作 | Fn 变体默认位置／动作 |
| --- | --- |
| F1–F10 | QWERTY 首行 q…p 右上，输出功能键事件 |
| F11 | 默认附加键开启时，沿用 o 左上位置 |
| F12 | 默认附加键开启时，沿用 p 左下位置 |
| 四方向移动 | 移动键四正向仍为光标上／下／左／右 |
| Home／PageUp／End／PageDown | 移动键左上／右上／左下／右下 |
| NBSP | 优先使用空格的空闲斜向；空格中心仍为空格／确认候选 |
| Insert／制表 | 对应原 Esc／Tab 的 Fn 变换，遵循相关附加键启用状态 |
| 重做／纯文本粘贴 | 对应 Undo／Paste 附加键的 Fn 变换，遵循其启用状态 |
| 货币、数学、希腊替代字形 | 继续使用固定上游 Fn 映射；不以分类符号页代替它们 |

中文 Fn 变体在原 ASCII 标点槽位使用 `（）［］｛｝。，！？；：`，Shift 输出各自明确的 ASCII 形式。`［］` 与 `【】` 不混为一组。发生替换时，原上游输出仍保留，优先放在 s／d／f 等中排空位；不覆盖原有隐藏槽位。

这些是默认位置，不禁止用户主动修改自己的 Fn 变体。配置的可选附加键、用户覆盖、额外数字行与横屏变换会影响最终呈现；不能仅凭默认位置说明声称任意自定义配置都已验证。

## 共享控制与迁移

空格上／下分别轮换下一个／上一个启用布局，左右保留 Slider。Enter 中心遵循编辑器动作，右下打开选择器。退格中心删前文，右上 Del 删后文。上述控制不因布局或 Fn 状态改变含义。

逐布局编辑器暂时把共享位置显示为只读；完整共享编辑和中心加八向总览属于 R5。旧的逐布局覆盖没有删除，但不再使这些共享位置各自漂移。

首次迁移保存 v1 的原始 Fn 目标、顺序、启用集合及覆盖数据；损坏的字段类型也先保留再恢复可用默认。布局导出格式为 v2，仍接受 v1 导入，并保存原始导入文本。用户词表与学习目录不参与布局迁移。

R3 的主界面拼音／可选注音快捷入口和辅助面板去重、R4 分类分页符号、R5 完整编辑器、R6 正式词包、R7 总体验收，仍按原计划继续。Compose 保持现状，高级手势编辑 H1 后置。
