## 保留的失败与环境恢复

原整合运行 40229771805 为 16／18，保留首次冷候选 20 秒不足及中文介绍将试输入框推至屏幕外的失败。后者修正为真实滚动到控件；新轮四条首装与两种词表完整流程已通过。

当前运行首次环境门禁在未安装应用的 API 23 guest 第二次 reboot 后失去 ADB，180 秒到期失败；新环境单项重试完成三次不同 boot_id 的实际 adb reboot。原失败不删除，也不将其归因于没有证据的应用／宿主原因。API 35 真实旧版升级的 prepare 阶段另被明确的“Pixel Launcher isn't responding”系统窗口遮挡；截图与 ANR 日志已保留，该失败未执行升级；相同 APK 在单独新 guest 重试后通过 prepare／verify／reboot 三阶段，分别为 16.333／18.627／22.670 秒。后续驱动仅对这个已观察到的具名外部窗口截图并关闭一次，应用自身异常仍失败。

失败诊断补充 ADB 原始 stderr 与当时设备清单，不延长原重启上限；截图继续留在 artifact，控制台只列文件名及大小，不再输出巨量 Base64。

脚本统一接受 `--timeout-seconds N`／`MIANCAK_SCRIPT_TIMEOUT_SECONDS`，默认 3600 秒；到期 124，嵌套共用剩余时限，取消转发信号并清理进程。ADB、instrumentation、重启与诊断另有更短上限。无法执行或超时的阶段不能记为通过。

## 试用与后续范围

安装前核对版本与签名。临时 debug 证书可能不同于此前交付；升级测试将旧／新／测试副本用同一临时证书签名，只证明数据迁移，不提供旧交付签名的兼容保证。正式稳定签名和商店分发仍是独立发布工作；不能通过卸载来证明学习数据无损升级。

首次使用按 Android 界面启用、选择 MIANCAK，直接输入 nihao、句号／逗号，再检查自己的 Fn 变体；键位见 KEYMAP.md／FN_LAYOUTS.md。布局设置可导出／恢复键位；“中文词表”单独管理兼容表及离线回退。布局文件不包含个人学习数据库。

未测试 ARM 真机，不保证全部厂商系统／编辑器。H1 手势编辑、带调或无编码词表转换、跨语言 cdict／Rime 共同源格式迁移及稳定发布签名继续按原计划独立处理。
