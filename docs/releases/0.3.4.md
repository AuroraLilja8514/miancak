# MIANCAK 0.3.4（候选版，尚未发布）

候选版的应用包名为 `org.miancak.keyboard`，versionCode 7，安装下限 Android 13（API 33），目标 SDK 36。正式发布仍需当前源码的 Android 15 门禁以及原签名证书的实际覆盖升级验收。正式下载当前为 v0.3.2。

- APK 保留离线引擎、经审查的 Lua 和配置及来源声明。通过**设置中文输入**下载固定的万象 Base v18.1.13 数据与简体语法模型。校验后可离线输入，支持从已校验的本地文件设置和复用已有兼容资源。初次设置前保留英文和字面直输。设定页可在离线时清理崩溃遗留的当前模型分片。见[设置与资源来源](../WANXIANG_SETUP.md)。
- 保留受支持的[词表导入](../RIME_WORD_TABLES.md)、[标准配置补丁](../RIME_CUSTOM_CONFIG.md)、已有部署和学习文件。旧学习条目可以预览后恢复为独立补充词表。新的模型和学习编码可能改变排序。见[学习恢复](../LEARNING_RECOVERY.md)。
- Shift 保留显式选择的内容，再提交剩余的原始字母。候选字号和左侧边距适配普通及展开模式，横屏字键更清晰，候选追加时保留有效触控目标。圆形手势完成后停止重复触发。见[Android 15 验收步骤](../ANDROID_ACCEPTANCE_RUNBOOK.md)。
- 新装默认不分体并显示 Sup/Sub。已有偏好、布局与配置按原值保留。设置条目与滑条保留对齐及保存状态，项目入口指向 MIANCAK 并保留上游归属。见[默认偏好](../DEFAULT_PREFERENCES.md)和[项目身份](../PROJECT_IDENTITY.md)。

候选版的设备运行结果、实际断网重启后的输入和与正式 v0.3.2 的同签名升级均待执行。打包后的 ABI 和 16 KiB 静态对齐不能代替 ARM 或实际 16 KiB 设备验收。见[发布约定](../RELEASING.md)。
