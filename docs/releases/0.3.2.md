# MIANCAK 0.3.2

这是当前输入界面修复的基线版本，也是首次使用 MIANCAK 长期发布证书签署的 APK。

- 恢复完整 Fn 配对及 F1–F12 实际功能事件。
- 中文候选可横向滚动、展开换行并选择后排候选。
- 符号按类别分页并支持跨类别循环。
- 键位编辑器使用正常尺寸预览，保留中心、八向、Shift/Fn 和已有手势设置。
- 改善中文括号、横屏触控和离线词表部署。

下载 Assets 中的 miancak-0.3.2.apk；SHA256SUMS.txt 与 release-provenance.json 提供文件哈希、源码、构建和证书信息。后续正式 APK 也将通过本仓库 GitHub Releases 发布。

此包的应用 ID 是 org.miancak.keyboard。此前交付的调试包使用 .debug 后缀，两者可以并存，不共享应用私有数据，不能按同包覆盖升级处理。请保留旧包及其数据；现有导出能力不等于完整学习数据迁移。

这是 N1–N4 开发前的版本：分体默认策略、Sup/Sub 默认显示、设置文字对齐以及应用内部分上游项目入口将在下一版本处理。当前反馈请提交到 https://github.com/AuroraLilja8514/miancak/issues ，不要通过旧界面入口向上游报告本分支的问题。

声明的最低版本为 Android 5.0（API 21）；实际完整 CI 使用 API 23/35。正式签名 APK 在 API 23/35 上另做安装、真实中英文输入、同证书覆盖安装、偏好与学习数据保留和真实重启检查。首次发布尚无旧正式版，覆盖安装场景为同一版本重装；真正的两版本正式升级将在下一版本完成。包含 arm64-v8a、armeabi-v7a、x86_64，尚无 ARM 真机验收。独立密钥备份恢复仍待维护者验证。
